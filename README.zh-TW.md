## 學術科研

課程學習、文獻整理、研究設計、資料分析與學術表達。

### Study Buddy 學習搭子

- **介紹**：面向大學課程的 AI 陪學 Skill，把課件、教材和往年題整理成知識點講義，銜接學期規劃、逐節學習和考前複習。
- **主要功能**：材料轉寫與講義整理；每週學習清單；自定義講解風格；小測與錯題本；模擬卷和考試提綱；演示、課程論文及作業檔案製作輔助。
- **適用場景**：同時學習多門課程、整理分散課件、準備期末考試或課程彙報。
- **使用說明**：初始化課程目錄後，將材料放入各課的 `原始资料/`，再提出整理或學習需求。當前依賴 Windows、Word / PowerPoint、Node.js ≥ 22.20 和 Python ≥ 3.10；OCR、圖片理解及 TeX 提綱需相應配置。Office 轉換使用 Windows COM。詳見[安裝說明](https://github.com/Liunian06/study-buddy#快速开始)。
- **GitHub**：[Liunian06/study-buddy](https://github.com/Liunian06/study-buddy)

### K-Dense Scientific Agent Skills

- **介紹**：覆蓋科學研究、資料分析和科研表達的 Agent Skills 集合。
- **主要功能**：文獻綜合、研究思考、科學資料庫與分析工具使用，以及科研寫作、圖表和彙報。
- **適用場景**：尋找文獻處理、資料分析與研究表達所需的專門技能。
- **使用說明**：按具體任務選擇模組，並檢視模組的 SKILL.md、依賴和安裝說明。庫內大量內容面向自然科學，社科研究應按方法和任務選擇。
- **GitHub**：[K-Dense-AI/scientific-agent-skills](https://github.com/K-Dense-AI/scientific-agent-skills)

### Anthropic Skills · 文件與資料處理

- **介紹**：Anthropic 釋出的 Agent Skills 示例集合，包含文件、PDF、演示和表格處理模組。
- **主要功能**：Word 文件處理、PDF 提取與製作、簡報製作、電子表格處理。
- **適用場景**：整理研究材料、製作報告和彙報檔案、處理表格資料。
- **使用說明**：在倉庫中選擇 docx、pdf、pptx 或 xlsx 等模組，按原說明配置環境；文件處理模組與其他示例的授權條件需分別檢視。
- **GitHub**：[anthropics/skills](https://github.com/anthropics/skills)

### interview-script · 訪談提綱

- **介紹**：用於產品研究的結構化使用者訪談提綱技能。
- **主要功能**：組織熱身、核心追問與收尾問題，圍繞實際經歷和既往行為提問。
- **適用場景**：準備使用者訪談，或為學術訪談提綱提供初步結構。
- **使用說明**：提供研究目的、訪談物件和關注問題。用於學術研究時，需要依據研究問題和方法調整，原框架採用產品研究與 JTBD 思路。
- **GitHub**：個人本地技能，未提供公開倉庫連結。

### summarize-interview · 訪談摘要

- **介紹**：把訪談轉寫稿整理成結構化摘要的技能。
- **主要功能**：提煉使用者需求、滿意度訊號、JTBD 和行動項。
- **適用場景**：整理訪談材料，快速回看主要內容。
- **使用說明**：提供訪談原稿和研究背景；摘要可輔助整理材料，正式質性編碼和主題分析需另行開展。
- **GitHub**：個人本地技能，未提供公開倉庫連結。

### sql-queries · SQL 查詢

- **介紹**：根據自然語言問題和資料庫結構生成 SQL 的技能。
- **主要功能**：讀取表結構、生成查詢，並適配 PostgreSQL、MySQL、BigQuery 等方言。
- **適用場景**：探索資料庫、提取研究資料、製作分析報表。
- **使用說明**：提供資料庫方言、表結構、欄位含義與所需結果，執行時檢查查詢條件和結果。
- **GitHub**：個人本地技能，未提供公開倉庫連結。

### grammar-check · 文字校對

- **介紹**：檢查文字語法、邏輯與銜接，提供區域性修改建議。
- **主要功能**：識別語法錯誤、表達不清和論述銜接問題。
- **適用場景**：校對論文草稿、研究報告和英文摘要。
- **使用說明**：提交文字並說明寫作目的與讀者；引文準確性和研究結論需根據原始證據核查。
- **GitHub**：個人本地技能，未提供公開倉庫連結。

## 作品集與設計

作品案例整理、視覺表達、遊戲廣告創意與展示材料製作。

### Anthropic Skills · 創意與設計

- **介紹**：包含創意、藝術、設計和文件製作示例的 Agent Skills 集合。
- **主要功能**：提供設計及內容製作的技能示例，支援瞭解技能組織方式與製作流程。
- **適用場景**：尋找視覺製作方法、設計任務參考和展示材料工具。
- **使用說明**：瀏覽倉庫的創意與設計模組，按具體技能說明確認所需工具、依賴與授權。
- **GitHub**：[anthropics/skills](https://github.com/anthropics/skills)

### ian-xiaohei-illustrations · 小黑正文配圖

- **介紹**：將中文文章的觀點、流程和隱喻轉成手繪解釋圖的技能。
- **主要功能**：提煉正文觀點、設計視覺隱喻、編寫配圖提示詞並檢查畫面；以小黑角色、白底和少量彩色批註組織畫面。
- **適用場景**：文章正文、方法說明和工作流程的輔助配圖。
- **使用說明**：提供正文與配圖位置，結合核心觀點確定畫面表達，再生成和檢查圖片。
- **GitHub**：個人本地技能，未提供公開倉庫連結。

### block-creative · 遊戲廣告創意

- **介紹**：面向 Block、重力與休閒解謎遊戲的廣告創意與指令碼評審技能。
- **主要功能**：競品素材拆解、創意變體、分鏡指令碼、逐段審稿與投放測試設計。
- **適用場景**：製作遊戲廣告創意案例、分析競品素材、修改分鏡指令碼。
- **使用說明**：提供影片、截圖或指令碼及任務要求；基於素材證據分析，投放表現需要透過實際資料判斷。
- **GitHub**：個人本地技能，未提供公開倉庫連結。

### review-resume · 經歷與成果梳理

- **介紹**：面向產品經理簡歷的評審和崗位匹配技能。
- **主要功能**：檢查結構、成果表達、關鍵詞與崗位相關性。
- **適用場景**：梳理個人經歷、提煉專案貢獻，為作品集案例敘事準備素材。
- **使用說明**：提供簡歷或經歷文字，可同時提供目標崗位；具體作品的設計過程與視覺展示需另行整理。
- **GitHub**：個人本地技能，未提供公開倉庫連結。

## 英語閱讀學習

英文閱讀後的表達練習與文字校對。

### grammar-check · 英文表達反饋

- **介紹**：用於英文閱讀後摘要和表達練習的輔助校對技能。
- **主要功能**：檢查語法、句間邏輯和表達銜接，給出針對性的修改建議。
- **適用場景**：讀完文章後寫英文摘要、複述或個人評論。
- **使用說明**：提供自己寫的英文與表達目標；如需核對摘要是否符合文章，應一併提供原文。
- **GitHub**：個人本地技能，未提供公開倉庫連結。

## 商業觀察

產品收入、商業模式、獲客方式與增長案例。

### How Profitable Startups Grow · BizPeel 產品收入與獲客清單

- **介紹**：彙集創業產品的收入區間、增長趨勢、賽道和獲客線索，關聯 BizPeel 的商業研究報告。
- **主要功能**：按收入、增長速度、近期新增和賽道檢視產品；提供創始人或官方賬號、增長問題與研究報告入口。2026-11-05 的倉庫說明收錄 742 個產品，作者說明按周更新。
- **適用場景**：獨立開發選題、競品觀察，以及 SEO、社交媒體和其他獲客渠道的案例學習。
- **使用說明**：GitHub 清單可公開閱讀，[中文入口](https://github.com/yihui-dev/how-profitable-startups-grow/blob/main/README.zh-CN.md)和 [BizPeel 產品庫](https://bizpeel.com/library)可進一步瀏覽。完整報告涉及解鎖或付費；收入區間來自公開資訊，需結合日期和來源理解，MRR 與近 30 天收入應分別看待。程式碼採用 MIT，表格內容版權歸 BizPeel，引用需署名。
- **GitHub**：[yihui-dev/how-profitable-startups-grow](https://github.com/yihui-dev/how-profitable-startups-grow)
