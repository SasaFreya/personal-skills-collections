## 收录与验证

参考 [Awesome Short Drama Skills](https://github.com/UnderleveledBuilder/awesome-short-drama-skills/blob/main/README.md) 的任务分类、组合推荐与验证状态做法，本文独立编写。

状态分为：已读公开说明、已核对本地技能、待筛选、已实测。本版没有效果实测；“已核对本地”仅表示文件存在且已阅读用途说明。公开仓库按仓库级收录，尚未逐项核对其中全部技能。不得将候选组合写成效果排名。

每项后续记录：来源、任务阶段、输入、输出、适用范围、依赖、授权、安装方式、核对日期、实测记录。安装命令以对应仓库为准；本版没有安装任何技能。

## 实测方式

每类选一个真实任务，分别比较普通提示词与启用技能后的结果，保留输入、模型、输出和人工判断。科研看证据可追溯性，设计看表达与交付，英语看独立理解和延迟回忆。

## 持续维护

本仓库集中管理四个方向，优先收录有明确用途、来源与使用边界的技能。

- 新线索先进入 [候选清单](BACKLOG.md)，核对后加入对应专题。
- “已实测”必须附任务、模型、日期与结果；实测记录放入 `evals/`。
- 每次更新记录在 [更新日志](CHANGELOG.md)。
- 推荐项目可使用 GitHub Issue 的收录模板，修改方式见 [贡献说明](CONTRIBUTING.md)。

本仓库当前仅提供索引与说明，不包含第三方技能源码，也不是可直接安装的技能包。外部项目的授权、安装和依赖以原仓库为准。
