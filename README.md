定位：新闻传播与社会科学研究，按“问题形成 → 文献检索 → 阅读与证据整理 → 研究设计 → 数据分析 → 写作与汇报”组织。

### Study Buddy 学习搭子

- **GitHub**：[Liunian06/study-buddy](https://github.com/Liunian06/study-buddy)
- **类型**：大学课程陪学 Skill；归入本专题的课程学习栏目。
- **介绍**：围绕老师提供的课件、教材、参考资料和往年题，整理课程知识点与讲义，并串联学期规划、逐节学习和考前复习。适合同时管理多门课程、资料分散、需要明确复习顺序的情况。
- **主要功能**：课程材料转写与讲义整理；按截止时间制定每周清单；自定义讲解风格；逐节讲解、小测和错题本；模拟卷与考前提纲；presentation、课程论文和作业文件的制作辅助。
- **基本流程**：初始化学习目录 → 将老师材料放入各课的 `原始资料/` → 整理讲义 → 选择讲解风格 → 按需学习、复习或制作课程交付物。原始材料保留，整理过程使用副本。
- **使用条件**：当前 README 要求 Windows、已安装的 Word 与 PowerPoint、Node.js ≥ 22.20、Python ≥ 3.10，以及支持 Skills 的 AI 助手。Office 文件转换和部分输出依赖 Windows COM；Mac 上的完整流程尚未验证。OCR 默认使用百度 Paddle，图片理解需要配置相应 VLM；材料可能发送至所配置的外部服务。考试提纲的 TeX 编译另需相关环境。
- **查看安装与使用**：[项目 README](https://github.com/Liunian06/study-buddy#快速开始) · [使用指南](https://github.com/Liunian06/study-buddy/blob/main/.claude/skills/study-buddy/references/introduction.md)。本记录未安装该技能。
- **来源与状态**：线索来自用户提供的小红书「小狗汪汪」《大学课程陪学 skill》截图（IMG_4484、IMG_4485）；已于 **2026-11-05** 对照原仓库 README 核对，**待试，未实测**。作者将其定位为课程及格与复习效率工具，不能据此推断科研质量或学习效果。

截图还提到同作者的旧项目 [ko-lesson](https://github.com/Liunian06/ko-lesson)，已找到对应仓库；它是独立项目，不将其功能和安装条件混作 Study Buddy 的说明。

## 英语阅读学习

按“选文 → 自主首读 → 难点讲解 → 理解检查 → 词汇积累 → 间隔复习 → 表达迁移”组织。

### 已核对的辅助技能

`grammar-check`（个人本地技能，公共来源待补）：检查语法、逻辑和衔接，可辅助检查自己的英文摘要。它不是专门的阅读教学技能，也未验证教学效果。

### 待筛选或定制的核心技能

下列是功能需求，尚未找到并核对对应的现成技能，不是可安装清单。

| 方向 | 需要的输入 | 预期输出 |
|---|---|---|
| 选文与难度校准 | 兴趣、近期阅读表现、候选原文 | 推荐理由和可解释的难度判断 |
| 精读陪练 | 原文、自己的初步理解、疑问 | 先给提示，按需解释语篇结构与长难句 |
| 阅读理解检查 | 原文、学习者答案 | 事实、推断、作者立场问题，以及原文依据 |
| 语境词汇整理 | 已读文章、自己标出的生词 | 原句、当前语境义、搭配与个人例句 |
| 间隔复习 | 历次记录与回忆结果 | 到期复习项目和掌握状态；需真实持久化存储 |
| 表达迁移 | 阅读内容、自己写的摘要 | 针对性反馈与二次尝试 |

### 候选学习组合

文章 → 自主首读并记录理解 → 针对卡点讲解 → 根据原文回答问题 → 整理少量高价值表达 → 英文摘要 → grammar-check 辅助反馈 → 后续回忆。

首轮实测使用一篇真实读物，检查讲解是否忠于原文、是否给足自主思考机会，以及隔天能否独立理解并回忆。自动复习和进度记录尚未实现。

## 商业观察

记录用于了解产品收入、商业模式、获客方式与增长路径的项目和资料。

### How Profitable Startups Grow · BizPeel 产品收入与获客清单

- **GitHub**：[yihui-dev/how-profitable-startups-grow](https://github.com/yihui-dev/how-profitable-startups-grow)
- **中文入口**：[简体中文 README](https://github.com/yihui-dev/how-profitable-startups-grow/blob/main/README.zh-CN.md)
- **相关网站**：[BizPeel](https://bizpeel.com/) · [产品库](https://bizpeel.com/library)
- **类型**：公开商业案例索引与数据清单，关联商业研究报告服务。
- **介绍**：汇集已有收入记录的创业产品，用月度经常性收入（MRR）区间、近 30 天增长趋势、所属赛道、创始人或官方账号以及获客问题，帮助寻找值得进一步研究的商业案例。可用于独立开发选题、竞品观察，以及 SEO、社交媒体和其他获客渠道的学习。
- **可查看的内容**：收入排名、增长较快的产品、近期新增产品、按赛道划分的清单；每个产品链接到 BizPeel 的研究报告。注意区分 MRR（月度经常性收入）与近 30 天收入，它们不是同一个指标。
- **数量与更新**：核对时仓库 README 标注 **742 个产品**，数据日期为 **2026-11-05**，作者说明按周更新。此处记录的是仓库当日标注，不承诺持续同步，也不表示已逐项审计收入。
- **免费与付费边界**：GitHub 清单可公开阅读，报告可免费预览；进一步查看完整报告涉及 BizPeel 的解锁或付费机制，以网站当时规则为准。公开清单不等于报告全文、完整数据库或平台源码均已开源。
- **数据与授权**：仓库说明收入区间整理自网络公开信息，详细报告提供相应来源；引用时仍需核查具体产品的数据日期、指标口径，以及公司披露和估算的区别。仓库代码采用 MIT，表格内容版权归 BizPeel，可按仓库说明署名引用；不能把代码授权直接套用到全部数据内容。
- **使用方式**：先选赛道和收入区间 → 挑选少量与自己资源接近的产品 → 查看产品及增长报告 → 记录用户、定价、获客渠道与可测试的做法。收入排名本身不能证明某个方向适合自己。
- **来源与状态**：线索来自用户提供的小红书「熠辉 indie」《开源！742个赚钱产品的收入与获客拆解》截图（IMG_4486）；已于 **2026-11-05** 对照原仓库 README 核对，**待试，尚无个人使用体验记录**。
